# ARFLO Antofagasta

Sitio estático compatible con GitHub Pages.

## Publicación

1. Copia `mi_logo.png` en esta carpeta.
2. Sube todo el contenido de `site/` a un repositorio de GitHub.
3. Activa GitHub Pages desde la rama principal.

## Administración

Abre `backend.html`. Los cambios se guardan en el navegador y aparecen al instante en el front. Para que sean públicos para todos:

1. Presiona **Exportar cambios**.
2. Reemplaza `catalog-data.js` en GitHub con el archivo descargado.

GitHub Pages no admite backend de servidor ni base de datos. Para edición global automática sin volver a publicar se necesita un servicio externo como Supabase o Firebase.
